# charter-agreement-protocol

Use [`@charter-agreement-protocol/verifier`](https://www.npmjs.com/package/@charter-agreement-protocol/verifier) directly:

```bash
npm install @charter-agreement-protocol/verifier
```

This package only re-exports `@charter-agreement-protocol/verifier`, so that this name leads to the same project. It adds no code of its own.

It accepts any newer version of `@charter-agreement-protocol/verifier`. If you need stability, depend on the scoped package and
commit a lockfile. This package is published by hand and carries no provenance attestation; the scoped package
is where releases and attestations live.
